# vineyard-establishment-using-xgboost
This repo contains work for my research thesis titled: land suitability analysis for new vineyard establishment using remotely sensed data and extreme gradient boosting

- Making use of a virtual environment is recommend (conda or venv)
    conda install -c conda-forge py-xgboost-cpu (explicitly specify the variant of xgboost)
    conda install -c conda-forge py-xgboost (conda should install the best variant on your machine if conda detects gpu)
